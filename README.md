# ShogunOS

**Multilingual worship presentation software** — hymnals and scripture in 20+ languages, offline-first.

Built specifically for **Lingfield High School** — song lyrics, scripture, and announcements projected live during services, with a stage view, queue, and remote control from a phone on the same network.

Created and developed by **[Ngaatendwe Manjeya](https://github.com/Bitzzh)**, formerly of Lingfield High School, as a gift to the school.

---

## Why ShogunOS

- **Offline-first, multilingual hymnals** — 20+ languages built in and available with no internet connection.
- **Quelea-compatible import** — bring an existing `.qsp` song library over directly.
- **Remote control** — drive the live screen from a phone on the same Wi-Fi.
- **Cross-platform** — Windows, macOS, and Linux via Electron.

## Setup (for Lingfield's own use/maintenance)

```bash
git clone https://github.com/Bitzzh/shogunos.git
cd shogunos
npm install
npm start
```

To build a distributable:

```bash
npm run make
```
